# Specialist Agents

These roles are orchestration lenses, not separate sources of truth. They share the same Drive Brain, governance, evidence vocabulary, and skills.

- `research-director.md` — external research program, verification, case studies, synthesis, gaps.
- `southbrook-diagnostic-agent.md` — local current-reality diagnosis across ministries.
- `interview-analysis-agent.md` — qualitative coding, cross-interview patterns, perception gaps.
- `measurement-strategy-agent.md` — measurement architecture, pilots, strategy/decision preparation.

The master Discipleship Assistant routes to a specialist only when the task benefits from that narrower perspective.


## Practice & Design Director

`practice-design-director.md` owns the bridge from external practice + mechanism research + Southbrook context to action-warrant assessment and bounded local testing.

Use it when the primary question is **what should we try or how should we implement**, not merely **what does the research say**.
