# Current Working Discipleship Language — Provisional

This file records concepts already present in current planning documents. It is **not** proof that the language is fully approved.

## Working concepts

### Discipleship Pathway
`Guest → Friend → Family → Parent → Sent`

### Discipleship Lifestyle
`Upward → Inward → Outward`

### Leadership Engine
`Identify → Invest → Launch`

### Discipleship Map
Two variants appear in current material:

- `Gather → Connect → Equip → Send`
- `Gather → Connect → Abide → Multiply`

Treat this as a live terminology conflict until leadership resolves it. Do **not** silently pick one and mark the other obsolete.

## Operating-system principle

The map names ongoing environments/rhythms; the pathway names movement/next steps; the lifestyle describes daily orientation; the leadership engine describes how leaders are raised and launched.

## Transformation test

The pathway must describe transformation rather than mere program completion. Ask what the person believes/practices, who knows them, how they obey Jesus, how they participate in mission, whom they are helping follow Jesus, and whether reproduction is beginning.
