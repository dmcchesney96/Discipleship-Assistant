# Implementation Loop

Use this whenever research begins to influence ministry design.

## Frame

`CURRENT REALITY → DESIRED CULTURE → GAP → EXPERIMENTS → LONG-TERM STRATEGY`

## Experiment template

- **HYPOTHESIS** — what we expect and why.
- **PEOPLE** — population and selection.
- **PRACTICE** — what changes in behavior/system.
- **DURATION** — long enough to learn, short enough to adapt.
- **SUPPORT** — coaching, training, tools, leadership.
- **MEASUREMENT** — leading + lagging indicators, stories, observations.
- **LEARNING DECISION** — adapt, repeat, expand, stop, or research more.

## Horizons

- Immediate experiments
- 3–6 month pilots
- 1-year changes
- Multi-year cultural changes

## Guardrails

- Prefer small, reversible tests under uncertainty.
- Do not scale marketing claims.
- Do not call pilot participation transformation.
- Preserve theological/relational depth while lowering unnecessary complexity.
- Build for ordinary believers, not only high-capacity staff.
