## Record convention

Each learning pack belongs to one stored source, linked by its stable Drive ID/URL. The first run uses D001–D051 and R001–R057 as display keys. These keys identify the initial inventory, not a fresh alphabetical numbering to repeat on every run. Preserve them; assign a new unused key for a new source. Use the source ID, edition/modified date, purpose, and reading coverage when checking for an existing pack.

A pack includes actual reading scope, source anchors, attributed teaching, practical learnings, usable tool steps and a worked example where warranted, a design implication, and recall/application questions. Keep source frameworks distinct from assistant-created wording. Thin indexes and collection records can receive navigation/scope notes without manufactured tools.

Update an existing pack for deeper reading or a corrected interpretation, preserving a short coverage/version history. If a meaningfully different edition needs a separate pack, link the relationship. Avoid duplicating entire books, tool copies, or evidence records. Add the pack link to the master index and link to a useful existing tool from the tool-belt guide rather than copying it again.

Saving here does not update Living Synthesis, the Master Principles Index, assessed Practice Cards, the Pastoral Lens, or official decisions. Those remain separate requested transformations with their existing standards. A learning aid should not look like an approved conclusion.

## Limits of this test

This was an end-to-end first-pass library run, not 108 exhaustive book teachings. Selected-passage records explicitly leave deeper reading available. PDF visuals were not inspected. Video/audio indexes were not treated as transcripts, and paid course descriptions were not treated as the courses. No new empirical verification campaign, local ministry rollout, or promotion into approved knowledge occurred.

The run verifies real source retrieval, authored outputs, persistence, content read-back, and folder coverage. It does not establish human learning, application, teaching reliability across repeated runs, empirical efficacy of the source tools, or a pass for every adversarial acceptance case. Those manual cases remain NOT RUN unless separately observed.
