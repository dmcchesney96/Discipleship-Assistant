# Resource & Equipping Intelligence — Separate Operational Lane

## Purpose
Fill the gap between understanding disciple-making practices and handing **usable, safe, reproducible tools** to ordinary people. Resource intelligence is *not* a third competing body of empirical evidence and is not a substitute for pastoral or theological judgment.

| Lane | Primary question | Unit of work | Typical durable output |
|---|---|---|---|
| Research / truth | What seems true and how strong is support? | Claim/study | Verified evidence, principle, Living Synthesis |
| Practice / design | What are ministries actually doing and might fit here? | Repeatable ministry practice/system | Practice Card, fit assessment, proposed pilot |
| **Resource & equipping** | Which actual materials and activity designs can help someone learn and do it? | Named worksheet, assignment, exercise, leader guide, teaching tool | Resource Review Card, comparison, original draft tool |

A source can be routed to more than one lane for *different questions*. A church leader manual may document a practice AND contain an exercise worth evaluating. Do not run all three workflows by default.

## Skill chain

`discipleship-resource-intake-cataloger → discipleship-resource-evaluator → discipleship-resource-comparison-extractor [only if 2+ comparable tools] → discipleship-training-tool-designer [only if drafting requested] → bounded test proposal → preservation / later pilot learning`

Orchestrator: `full-discipleship-resource-equipping-cycle`, which sequences bounded specialists but does not replace them.

### Routing examples
- "I uploaded some handouts; just inventory them." → Intake only.
- "Evaluate this one Bible discussion guide." → Evaluator only.
- "Compare these four assignments for teaching prayer." → Intake as needed → evaluate → compare.
- "Use these reviewed resources to make an original coaching card." → Tool designer with relevant reviews and pastoral lens.
- "Go through this resource folder, compare the strongest, and draft what we should try." → Full resource/equipping cycle.
- "Build an eight-week class from the Brain." → Full curriculum build (may call resource evaluator on a small subset).
- "Research whether feedback increases transfer." → Research/truth workflow.
- "Which church practice should Southbrook pilot?" → Full practice/design workflow.

## Rights and reuse
A downloaded/free/public PDF may still be copyrighted. Preserve citation, original owner, version and explicit use permissions. Respect licenses and restrictions for copying, public distribution, modifying, translation, branded reuse, and internal circulation. Permission unknown is not permission granted. Where rights are uncertain, study high-level methods, create genuinely original wording and design, and seek clarification before copying/adapting substantial protected expression. Never blindly recombine proprietary curricula.

## Three status dimensions—do not collapse
1. **Review coverage**: DISCOVERED → INDEXED → EVALUATED (or LIMITED / INACCESSIBLE).
2. **Design recommendation**: CONSIDER AS-IS; ADAPT IF PERMITTED; ORIGINAL DESIGN; TEST ALTERNATIVES; NEEDS INFO; NOT NOW.
3. **Southbrook authorization/use**: PROPOSED DRAFT → HUMAN-APPROVED PILOT MATERIAL → PILOT TESTED → HUMAN-APPROVED TOOL (or RETIRED). These are not automatic advancements; actual record/authority required.

Resource quality judgments are distinct from reported outcomes and research confidence. Real impact should only be discussed from genuine observed local outcomes or supported studies, with limitations.

## Drive architecture (proposal, not an assertion of existing folders)
- Keep **originals** in an existing verified source folder, e.g. `02 — EXTERNAL EVIDENCE LIBRARY / 07 Practitioner Books, Training & Tools`, or the correct original owner area.
- Existing `04 — RESEARCH INTELLIGENCE / 06 Practice Intelligence Library` continues housing **practice families**.
- **PROPOSED NEW SIBLING:** `04 — RESEARCH INTELLIGENCE / 07 Resource & Equipping Intelligence` with:
  - `01 Resource Intake Index & Manifests`
  - `02 Resource Review Cards`
  - `03 Resource Comparisons & Design Patterns`
- **Drafts** remain in verified `11 — AGENT WORKSPACE` or a project-design location; pilot materials/results in `09 — EXPERIMENTS, PILOTS & LEARNING` if authorized; approved tools in the appropriate local ministry/operating system folder.
- Do **not** create or assert these three new folders automatically. Live Drive metadata, user authorization, access checks and verified filing are required. Until provisioned, keep links in a temporary authorized existing destination or deliver reviews in the chat.

## Handoffs without loop inflation
- Consequential empirical/causal claim → `source-evidence-checker`
- Practice-family documentation → `discipleship-practice-intelligence-builder`
- Larger ministry fit judgment → `southbrook-practice-fit-assessor`
- Complete course → `full-discipleship-curriculum-build-cycle`
- Approved pilot implementation kit → `discipleship-practice-implementation-kit-builder`
- After actual local test → `discipleship-pilot-learning-evaluator` (when a true pilot), or ordinary revision notes for quick usability checks
- Presentation/branding → `southbrook-brand-artifact-stylist` after content settled
- Durable research principle → Living Synthesis **only after separate evidence justification**.

## Chain quality checks
Every evaluated item must trace back to exact original content. Every recommendation must state a concrete intended capability, risks, review coverage, rights and local uncertainties. Every design must identify whether it was created, simulated/tested, pastorally approved, or actually piloted. User should be able to request just one narrow stage without triggering an expensive whole pipeline.

## Success
A reproducible, permission-aware chain from real ministry material to honest review, useful design patterns, practical original tools and eventual actual-use feedback—without claiming that polished resources constitute proven outcomes.
