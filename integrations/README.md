# Integrations

## Google Drive
Primary durable Second Brain and source library. Use live Drive when current state, file organization, or current content matters. Preserve stable file identity and provenance.

## GitHub
Operating system for the assistant: constitution, skills, agent roles, tests, technical documentation. Do not store the private research corpus or sensitive pastoral data here.

## Public web/research sources
Use for external verification, current organizational information, primary public documents, and scholarly/practitioner research. Cite material claims and distinguish organizational claims from independent evidence.

## Communication/calendar/other systems
Use only when the user's task actually requires them and authorization is present. Research skill selection does not itself authorize sending, scheduling, purchasing, or committing the church.
