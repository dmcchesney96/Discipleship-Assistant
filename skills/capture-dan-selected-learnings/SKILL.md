## Required source citations: Turabian footnotes (Dan's standing rule, November 20, 2026)

This applies whenever Dan selects a source-derived learning, truth, principle, or conviction for the Brain, including a resource insight he restates in his own words. It is required for new captures and for substantive updates to existing captures, not just for research reports.

- Reopen the original source in the Brain before saving. Cite the actual author or organization, exact work/title, edition and publication information when available, and printed page(s), chapter, section, or other precise locator. Retain a stable link to the Brain copy and, if available, the original publication. A link alone or a generic source list is not a citation.
- Use Turabian notes-bibliography style, with numbered superscript footnote markers immediately after each direct quotation, attributed paraphrase, or source-dependent claim. Use real native Google Docs footnotes when supported, and verify their contents and marker placement on readback. If native footnotes cannot be created or verified, use numbered superscript markers and a clearly labeled Footnotes section in Turabian format; report that fallback in the final response. Do not silently substitute bare URLs or author-date references.
- Use a full first note for each distinct source and a shortened author/title/page note for subsequent references. Book example: Firstname Lastname, *Book Title* (City: Publisher, Year), 23–24. Journal example: Firstname Lastname, “Article Title,” *Journal Name* volume, no. issue (year): specific page(s), DOI or URL. Web example: Firstname Lastname, “Page Title,” Organization or Site, Month Day, Year, URL. Use the appropriate Turabian form for the actual resource type, including an access date for undated online material when needed. Do not invent missing dates, publishers, editions, page numbers, authors, or URLs; record the available metadata and identify any unverified locator.
- Distinguish an author's direct quotation from paraphrase, Dan's endorsement/own formulation, and assistant-created wording. Cite the source that actually supports the idea, not the assistant synthesis as if it were an author's quotation. For Scripture, use book, chapter, and verse and specify the translation when quoting; do not fabricate an external source for Dan's original thought. Where a source is only available through a secondary quotation, explicitly mark “quoted in” and cite the source actually consulted.
- For a learning or conviction developed from several explicitly selected or approved sources, keep one canonical record and attach each approved source at the specific wording it supports. Add a compact source-contribution section when useful: author/work, exact quotation or paraphrased idea, locator, and how it supports, deepens, qualifies, or differs from the conviction. Distinguish converging views from disagreement; do not attribute the combined formulation to a single author.
- Dan's standing approval gate (November 20, 2026; supersedes prior proactive-enrichment authorization): NEVER independently add supporting sources, excerpts, quotations, paraphrases, or related insights to an endorsed learning or conviction record. If Dan requests research or excerpts, retrieve relevant Brain sources and present candidates in chat, with the original attribution, precise locator, and Turabian citation, and explain how each might contribute. Wait for Dan to explicitly identify or approve the material to add before writing it to the Brain. A request to save one learning or conviction authorizes only that selected content and the citations necessary to substantiate it, not additional supporting material. A request to find, review, compare, or show sources is read-only, not permission to save them. Keep unapproved suggestions out of the canonical document, lens, index, and raw capture of endorsed sources. When Dan approves specific additions, append only those to the existing canonical record, preserving earlier content and footnotes. Do not assume his endorsement of a source merely because it aligns with his convictions.
- When Dan explicitly authorizes adding a new source to the same conviction, locate and extend the existing canonical document in place. Keep earlier wording, endorsement dates, footnotes, source links, and change history intact; add the new source and its distinct contribution with a dated note. Revise the core conviction only if warranted by Dan's instruction; do not silently replace an earlier view or create duplicate learning records. Maintain sequential notes and use shortened citations where appropriate. Update the existing index and Pastoral Lens pointer as necessary.
- Before delivery, check that each substantive source-derived idea and quotation has a matching note, the locator and attribution are faithful to the consulted source, each note points to its correct source, and all added links and footnotes are present. If a source is unavailable or metadata incomplete, label it explicitly, preserve the endorsed idea without invented attribution, and distinguish pending verification from completed citation.

For source-derived convictions, use this skill for the full citation-bearing selected-learning record and coordinate with `discipleship-convictions-capture` for the concise canonical lens entry and raw capture. Apply the Turabian footnote requirement to every document created or substantively updated in the capture workflow, including raw pastoral selections, the Start Here index, and the Living Convictions lens, whenever that document names, quotes, paraphrases, or makes a claim drawn from an external resource.
