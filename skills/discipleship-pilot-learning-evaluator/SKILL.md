# Discipleship Pilot Learning Evaluator

## Purpose

Answer:

> **What did this Southbrook test actually teach us, what did it not teach us, and what is the responsible next action?**

This closes the loop between practice design and durable local learning.

Use `docs/research-practice-action-framework.md`.

## Trigger

Use when:

- a Southbrook experiment/pilot has completed;
- meaningful interim pilot data exists;
- the user asks "what did we learn?";
- leaders need to decide whether to stop, adapt, repeat, expand, or consider scale.

Do not use this skill merely to design the pilot. Use `discipleship-experiment-pilot-designer` first.

## Inputs

Retrieve:

- original Pilot Charter;
- original hypothesis/mechanism;
- pre-stated decision criteria;
- measurement plan;
- baseline when available;
- participation/reach data;
- adoption/fidelity data;
- burden/coaching/staff-load data;
- discipleship outcome signals;
- stories/interviews/leader observations;
- reproduction/multiplication signals;
- adaptations made during the pilot;
- relevant Southbrook context changes.

## Workflow

1. Restate the original hypothesis, mechanism, people, duration, and decision criteria.
2. Assess evidence coverage/quality before interpreting results.
3. Evaluate **implementation**:
   - reach;
   - adoption;
   - fidelity;
   - dosage/cadence actually delivered;
   - friction/burden;
   - coaching demand;
   - staff dependence;
   - participant/leader experience;
   - reproducibility;
   - adaptations.
4. Evaluate **discipleship learning**:
   - abiding;
   - transformation;
   - community;
   - mission;
   - disciple making;
   - multiplication;
   - stories/pastoral discernment.
5. Distinguish:
   - **IMPLEMENTATION FAILURE** — people did not/could not carry the practice as intended;
   - **MECHANISM/OUTCOME FAILURE** — the practice was carried with reasonable fidelity but the expected change did not appear;
   - **INSUFFICIENT EVIDENCE** — sample/duration/data are too weak to judge;
   - **PROMISING LOCAL SIGNAL** — useful local evidence but not enough for broad claims;
   - **STRONG LOCAL LEARNING** — repeated/clear enough to justify a larger local action warrant.
6. Identify subgroup/context differences and unintended effects.
7. Compare actual results with the pre-stated decision criteria; do not move the goalposts after seeing results.
8. Update the local action warrant:
   - STOP;
   - ADAPT;
   - REPEAT;
   - EXPAND CAUTIOUSLY;
   - INTEGRATION CANDIDATE;
   - SCALE CANDIDATE;
   - RESEARCH MORE.
9. State what would need to be true before the next larger action.
10. Preserve the result in the Brain and link it to the original Practice Card, fit assessment, pilot charter, and measurement plan.

## Generalization boundary

A Southbrook pilot is **local evidence**, not automatically a universal discipleship principle.

A positive result may:
- strengthen Southbrook fit;
- raise local action warrant;
- reveal implementation conditions;
- generate a research question;
- sometimes contribute to broader synthesis when combined with independent evidence.

Do not call one local pilot "proven."
