# Operational verification register

| ID | Bounded claim/field | Claim type | Source/version/locator | Access depth | Audit status | Supported meaning | Contrary/missing evidence | Corrected wording | Next action |
|---|---|---|---|---|---|---|---|---|---|

Retain Core evidence strength/rationale and source-family ID where assessed. State checked/unchecked counts and sampling boundaries.

Separately list operational fields DOCUMENTED / PARTIAL / UNKNOWN / NOT APPLICABLE. Explain what each gap prevents. Do not compute an effectiveness score from completeness.

Example: A manual directs a weekly three-person meeting. Verify prescribed cadence/group size at exact locators. Actual compliance and spiritual outcomes remain unknown without separate records. If an interview describes groups of three to five, preserve setting/date differences rather than averaging four.
