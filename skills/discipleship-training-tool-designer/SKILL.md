# Discipleship Training Tool Designer

## Purpose
Answer: **What is the smallest practical, biblically responsible tool an ordinary believer can use to practice this discipleship capability and eventually help someone else do it?**

Designed for one or a few connected tools. Multi-session progression belongs to `discipleship-curriculum-architect`; implementation kits for already-selected pilots belong to `discipleship-practice-implementation-kit-builder`.

## Natural trigger
"Make our own worksheet," "draft the assignment," "turn these evaluations into a small-group guide," "create a printable role-play," "design a coaching card," or selected design step in the full resource chain.

## Required inputs
- User's target audience/context, capability/outcome, time and setting
- Relevant Resource Review Cards and/or comparison, exact original source locators
- The smallest relevant `USER ALIGNMENT / PASTORAL LENS` (Bible & Curriculum Design Philosophy)
- Relevant biblical/approved doctrinal guardrails, current Southbrook constraints, leader/participant needs
- Rights and reuse boundaries; any approved branding constraints

If no comparison exists for a single resource, use its Review Card. If no actual source is accessible, label design as based on user description or general pedagogical reasoning, not a sourced synthesis.

## Process
1. **Backward-design:** write a behavioral goal in observable terms (e.g. "can facilitate a 15-minute Bible conversation using a fresh passage with feedback"). Avoid claiming measured heart change.
2. **Choose minimum viable structure:** participant handout, facilitator guide, practice/rehearsal exercise, take-home application, or coaching quick reference. Resist content bloat.
3. **Start with Scripture and faithful interpretation** when biblical claims are part of the tool; distinguish pastoral choices from verified research. Escalate weighty doctrine/authority to leaders.
4. **Make learning active:** where appropriate, `MODEL → GUIDED TRY → REAL PRACTICE → FEEDBACK → FOLLOW-UP → TEACH-BACK`. Not all activities require every step, but do not confuse reflection-only with practice.
5. **Increase responsibility gradually:** early witness, testimony, prayer and simple Scripture conversations may be supported; counsel, teaching authority and leadership require suitable competence/oversight.
6. **Write original content:** use functional ideas and general methods learned from reviewed materials; do not copy protected wording, exercise structure wholesale, or distinctive branding without permission. Record each inspiration source and licensing decision.
7. **Include effective instructions:** who, when, supplies, duration, facilitator script, participant action, what to do if stuck, safe debrief, next real-life step, optional accommodations, coaching/feedback, guardrails.
8. **Facilitator and participant perspectives:** instructions must work without the assistant present. Make leader burden and staff dependencies explicit.
9. **Quality check by simulated walk-through** (not an actual pilot): can a novice understand instructions, complete task in allotted time, demonstrate capability, receive useful correction, and explain/repeat the process?
10. **Human review gate:** doctrine, vulnerable populations, personal disclosures, minor safeguarding, and rights. Do not imply approval.
11. **Publish only requested formats:** editable master plus printable format when user requests, using artifact production/branding skills as needed; render/inspect final deliverable where tooling supports it.

## Required output: Training Tool Packet
- Status: `SOUTHBROOK DRAFT — NOT APPROVED / NOT PILOT TESTED` (unless verified otherwise)
- Target audience, capability, context and time budget
- Actual tool text with clear instructions
- Facilitator directions/coaching/feedback prompts as needed
- Participant action and real-life transfer / teach-back when appropriate
- Safeguarding/authority/theological boundaries
- Source inspiration ledger + rights/reuse disposition
- Quality check: what was reviewed, what remains untested
- One small feasible field-test idea; no invented results
- Editable/printable file links only if created and verified

## Stop and persistence
Drafts go to a verified temporary design workspace/approved project destination. They do not automatically become approved curricula, public materials, or Living Synthesis. Move into `09 — EXPERIMENTS, PILOTS & LEARNING` only for an authorized pilot; route completed local learning through `discipleship-pilot-learning-evaluator` (or targeted resource usability findings when not a full pilot).
