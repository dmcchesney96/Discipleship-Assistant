# Institutional Memory Writer

## Purpose

Capture the things a future leader/agent should not have to rediscover.

## Good memory candidates

- approved decisions and why they were made;
- definitions and operating principles that are genuinely current;
- repeatable workflows;
- experiment results and lessons;
- known failure modes and safeguards;
- changed assumptions and what evidence changed them;
- stable handoff knowledge.

## Do not promote

- brainstorming;
- one-off opinions;
- unresolved research claims;
- sensitive personal narratives;
- stale historical procedures as current;
- recommendations that were never approved.

## Workflow

1. Identify durable proposition/lesson.
2. Link to original evidence/decision.
3. Record date, status, scope, rationale, constraints, and review trigger.
4. Preserve prior versions as HISTORICAL/SUPERSEDED when changed.
5. File in the existing Brain location that owns the concept.

## Output

- Proposed memory entry
- Why durable
- Source(s)
- Status
- Destination
- Review trigger
- Applied/proposed/blocked result
