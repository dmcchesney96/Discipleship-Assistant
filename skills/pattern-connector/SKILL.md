# Pattern Connector

## Purpose

Make the Brain smarter as evidence accumulates instead of becoming a warehouse.

## Workflow

1. Define the pattern/question narrowly.
2. Gather already-assessed evidence from independent sources and/or local evidence.
3. Compare definitions, populations, units, mechanisms, and outcomes.
4. Identify:
   - convergence;
   - meaningful disagreement;
   - context-specific practices;
   - recurring failure modes;
   - plausible mechanisms;
   - research gaps.
5. Distinguish external convergence from Southbrook-local confirmation.
6. Distinguish a **repeated practice pattern** from a **transferable principle**. Repeated use across churches can justify a Practice Intelligence pattern without proving the practice causes the outcome.
7. Formulate a transferable principle only when evidence supports it.
8. Tag confidence and state what would falsify/change the conclusion.

## Output

- Pattern statement
- Evidence map
- Convergence/divergence
- Mechanism candidates
- Principle (if warranted)
- Southbrook relevance
- Confidence
- Open questions / next research

Do not update the Living Synthesis automatically; route a supported mechanism/principle change to `living-discipleship-synthesis-maintainer`.

When the main new learning is **how a practice is implemented or repeated across contexts**, route it to `discipleship-practice-intelligence-builder` / Practice Intelligence Library instead.
