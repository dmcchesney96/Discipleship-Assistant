# Southbrook Brand Artifact Stylist

## Purpose

Turn a finished or substantially defined ministry artifact into something that visibly belongs to **Southbrook Church**.

This is a **brand layer**, not a content strategy skill.

It should help future artifacts share recognizable Southbrook visual DNA without forcing every document into the exact same layout.

## Trigger

Use automatically when:

- Dan explicitly asks for something to be Southbrook-branded, on brand, or to use the Southbrook logo/colors/style;
- a requested artifact is clearly intended for Southbrook leaders, volunteers, parents, students, members, or public ministry use and visual branding would materially improve it;
- another skill creates a run-ready Southbrook ministry tool and the artifact is being turned into a polished DOCX, PDF, handout, one-pager, workbook, guide, or presentation.

Do not auto-apply when:

- the artifact is a raw research/evidence record in the Discipleship Brain;
- the user requests a different visual identity;
- the artifact is intentionally plain-text or utilitarian;
- branding would create false authority, such as a tentative proposal that could be mistaken for approved church policy.

For proposals or pilots, preserve clear status language such as **PROPOSED**, **DRAFT**, or **PILOT** even when the artifact is visually branded.

## Source priority

When brand sources disagree, use this order:

1. current explicit user direction;
2. a current official Southbrook brand guide or asset supplied by Southbrook;
3. current official Southbrook website and current official logo assets;
4. current Southbrook ministry artifacts that clearly reflect accepted practice;
5. older Drive assets / historical examples;
6. inferred design choices.

Never promote an inference into an official brand rule.

Read `references/brand-profile.md` before substantial branded artifact creation.

## Current verified brand foundation

### Primary color

**Southbrook cyan:** `#00AEEF`

- Current website inspection in October 2026 exposed `rgb(0, 174, 239)`.
- A Drive full-color Southbrook logo uses a nearly identical `#00ADEE`.
- For newly generated shapes, rules, headings, and table headers, default to `#00AEEF`.
- Never recolor the logo itself to force an exact token match.

### Dark color

**Deep Southbrook navy:** `#002A40`

Use selectively for strong dark backgrounds, title bands, or slide sections when a dark field is appropriate.

### Neutrals

- Professional print charcoal: `#231F20`
- Logo / legacy charcoal: `#404041`
- Practical internal-document charcoal: `#2A2929`
- Secondary gray: `#6B6E70`
- Professional supporting gray: `#939598`
- Near-white gray: `#F7F9FA`
- Pale cyan callout: `#E5F7FD`
- White: `#FFFFFF`

For professionally designed print pieces, prefer `#231F20` as the dark neutral because it appears directly in the approved Kelly-produced Milestone 2 Finals and the 2026 Discipleship Group Booklet.

Use color sparingly. Southbrook artifacts should feel clean and high-contrast rather than heavily decorated.

## Typography

### Professional / outward-facing design

**Gotham family — HIGH CONFIDENCE working precedent.**

Recent independent Southbrook professional-design sources converge on Gotham:

- Kelly Manus-owned `Milestone 2 Finals` from summer 2025;
- the 2026 `Discipleship Group Booklet.pdf`;
- the 2026 Kelly-owned senior invitation, which uses Gotham Condensed Medium plus an event-specific display font.

Verified Gotham variants include Gotham Book, Gotham Bold, Gotham Book Italic, and Gotham Bold Italic.

Use Gotham when an authorized production environment already has a licensed copy or a current Communications template contains it.

Do **not** extract, redistribute, attach, or package Gotham font files.

Do not call Gotham the formally published "official Southbrook font" unless Communications or a formal brand guide explicitly confirms that wording.

### Website typography boundary

The current website uses a modern sans-serif treatment and Adobe Typekit resources, but the exact current website CSS font family has not been independently verified.

Do not assume the website CSS font is Gotham merely because Gotham is strongly supported by professional print precedent.

### Editable internal-document fallback

Recent editable Southbrook ministry documents use **Arial** extensively.

When Gotham is unavailable:

- use Arial for DOCX/PDF ministry artifacts that need broad editability;
- use Arial Bold for major titles and section heads;
- use Arial Italic sparingly for subtitles or reflective prompts;
- use a compatible clean sans-serif only when Arial is unavailable.

Arial is a practical fallback, not the primary professional-design identity font.

Practical letter-size defaults:

- title: 22–28 pt bold, charcoal;
- subtitle: 10–12 pt italic, gray;
- section label: 9–11 pt bold, often uppercase cyan;
- body: 9–11 pt charcoal;
- footer/metadata: 7–9 pt gray.

Adjust for accessibility, audience, and format rather than forcing these sizes mechanically.

For slides, scale the same hierarchy appropriately; do not carry document font sizes directly into presentations.

### Logo-use rules

- Prefer an actual approved logo asset; do not recreate the wordmark with typed text.
- Keep original proportions.
- Never stretch, squash, skew, crop through the mark, add a drop shadow, bevel, gradient, or decorative outline.
- Do not recolor a supplied logo unless the user provides an approved alternate.
- Leave generous clear space around the logo.
- Use the full wordmark when the artifact needs clear church identification.
- Use the simple mark only when context already identifies Southbrook or the available space is too small for the wordmark.
- On a light document page, prefer the full-color/dark-wordmark variant.
- On a dark field, use the website light/white-compatible variant when available.
- If a current official asset can be retrieved, prefer it over an older local copy.

## Southbrook document DNA

The strongest recurring pattern across the current website and recent ministry artifacts is:

- clean modern sans-serif typography;
- strong cyan accent;
- charcoal or dark navy text/background;
- generous white space;
- square/rectangular geometry rather than rounded decorative cards;
- restrained use of color;
- uppercase navigation/section labels;
- strong visual hierarchy;
- simple rules and bands;
- practical ministry information presented in clear tables, callouts, or action rows.

For DOCX/PDF ministry tools, a strong default pattern is:

1. small Southbrook logo at upper left;
2. optional ministry/document type at upper right;
3. thin cyan rule;
4. large charcoal title;
5. short gray subtitle;
6. uppercase cyan section labels;
7. body text in charcoal;
8. pale cyan callouts for the single most important goal/instruction;
9. cyan table header with white text when a table needs emphasis;
10. light neutral rows/backgrounds;
11. small gray footer with Southbrook/ministry identity and page number.

Do not force all eleven elements into every artifact. Simplicity is part of the brand.

## Web / slide visual cues

When creating slides, screens, or event graphics:

- cyan + deep navy + white can carry more of the page than in a printed document;
- keep type bold, sans-serif, and high contrast;
- favor clean rectangular blocks and full-bleed imagery over ornamental church graphics;
- use uppercase labels sparingly for navigation/category hierarchy;
- preserve generous margins and negative space;
- avoid generic AI-church aesthetics such as glowing crosses, faux paper textures, ornate gradients, excessive script fonts, or decorative flourishes unless the user explicitly requests them.

## Workflow

### 1. Confirm artifact role

Determine:

- audience;
- internal vs public;
- approved vs proposed/pilot;
- print vs screen;
- document vs presentation vs card/handout;
- accessibility needs.

### 2. Retrieve the brand profile

Read `references/brand-profile.md`.

For substantial Southbrook artifact production, also use the canonical Drive working folder:
`Southbrook Brand Reference — Current`
(`11XwWKHKFa_-9qhmnUQ2sG_IgMnCDhE3-`).

Treat Kelly Manus's `Milestone 2 Finals` folder as an approved professional-design precedent set, not as a template that must be copied mechanically.

If the user supplies a newer official guide/logo/font direction, that overrides the profile and the profile should be updated only with authorization.

### 3. Preserve the content architecture

The content-owning skill determines what the artifact needs to accomplish.

Branding must not:

- add unsupported claims;
- remove evidence/status labels;
- reduce usability;
- make a proposal look approved;
- turn a simple ministry tool into a design-heavy brochure.

### 4. Obtain logo asset

Prefer a current official website asset. If that is not practically retrievable in the active artifact environment, use the verified Drive fallback.

Do not use a low-resolution screenshot of the logo when a clean source asset is available.

### 5. Apply the design system

Use the verified color tokens, typography boundary, hierarchy, spacing, and logo rules above.

### 6. Render and inspect

Use the artifact-specific production skill:

- DOCX: follow the DOCX render → inspect → iterate workflow;
- PDF: follow the PDF generation/verification workflow;
- slides: follow the slides creation/verification workflow;
- spreadsheets: follow spreadsheet-specific style guidance.

Brand QA happens after functional/layout QA, not instead of it.

### 7. Run brand QA

Check:

- correct logo asset and proportions;
- Southbrook cyan used consistently;
- text remains high contrast;
- Gotham is used only where legitimately available and is not mislabeled as formally published "official" unless confirmed by Communications;
- typography hierarchy is consistent;
- whitespace is sufficient;
- tables/callouts are restrained;
- status labels remain visible;
- document still feels practical, not over-designed;
- no unrelated ministry/sub-brand logo has been substituted for the main church brand.

## Artifact QA questions

Before finishing, ask:

1. If the logo were removed, would the palette/type/hierarchy still feel consistent with Southbrook?
2. Does this look like ministry communication rather than a generic AI template?
3. Can the intended person find the next action in seconds?
4. Is cyan functioning as an identity/hierarchy signal rather than visual noise?
5. Does the artifact preserve Southbrook's simple, modern, high-contrast feel?
6. Is any brand assumption being presented more confidently than the evidence supports?
7. If this is a proposal/pilot, is its non-approved status unmistakable?

## Output note

When useful, record a short implementation note:

- logo source used;
- font family used;
- primary color token;
- any brand uncertainty or exception.

Do not burden ordinary end users with this note unless it belongs in production metadata.

## Persistence

This GitHub skill is the working visual-brand rule set for artifact generation.

The **official Southbrook website and any future official brand guide/assets outrank this skill**.

When an official brand guide is later provided, update this skill/profile rather than layering contradictory rules on top.

## Stop conditions

Stop when:

- the artifact is visibly consistent with the verified Southbrook identity;
- the next improvement would be decorative rather than functional;
- an unresolved official-brand question requires a current source or human confirmation;
- the user requested only content and not artifact production.
