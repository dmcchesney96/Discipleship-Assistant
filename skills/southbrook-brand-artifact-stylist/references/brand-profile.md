## Working typography

### Document default

Use Arial unless a current official typography source is supplied.

Recommended hierarchy for letter-size ministry documents:

- Title — Arial Bold, 22–28 pt
- Subtitle — Arial Italic, 10–12 pt, gray
- Section label — Arial Bold, 9–11 pt, cyan/uppercase when useful
- Body — Arial, 9–11 pt, charcoal
- Table header — Arial Bold, white on cyan
- Footer — Arial, 7–9 pt, gray

This hierarchy is a working production system derived from current artifact practice, not an official published typography standard.

## Working layout grammar

Southbrook ministry artifacts should generally feel:

- modern;
- clean;
- direct;
- spacious;
- practical;
- action-oriented;
- lightly branded rather than heavily decorated.

Prefer:

- square corners;
- rules/bands;
- clean tables;
- clear action boxes;
- concise labels;
- generous page margins;
- strong hierarchy.

Avoid by default:

- ornate church imagery;
- script/display fonts;
- gradients without a specific reason;
- oversized decorative icons;
- excessive cyan;
- rounded-card UI aesthetics copied from consumer apps;
- generic AI-generated Christian visual tropes.

## Logo handling

Do:

- preserve proportions;
- use a clean source asset;
- leave generous clear space;
- use the full wordmark when identification matters;
- use the simple icon only when context is clear.

Do not:

- stretch;
- skew;
- crop the mark;
- add shadows/outlines;
- recolor without an approved variant;
- replace the actual wordmark with typed text.
