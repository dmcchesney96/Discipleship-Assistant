# Principle synthesis — focused acceptance packet

**Purpose:** Exercise the new evidence-to-principle workflow with cases that commonly contaminate a research Brain. These are bounded behavioral cases to be *executed* by the assistant with actual accessible artifacts, plus expected dispositions; a written test case is not itself a passed test.

## Case A — Adjacent-domain evidence is not disciple multiplication
- **Corpus:** Existing Brain Protégé Effect / Learning by Teaching research, How Soon Should a Disciple Become a Disciple-Maker research, and Biblical Reading and Reproducible Disciple Making Findings (BRP01–BRP06).
- **Challenge:** Conclude whether learning while teaching proves third-generation discipleship multiplication.
- **Expected:** Learning/feedback mechanism is supported; church multiplication outcomes not established; PROMISING or CONTEXT DEPENDENT where warranted, not HIGH CONFIDENCE for G3 reproduction. Reused primary learning studies within reports count once per study family. No duplicate BRP principle IDs.
- **Evidence access:** Read the original/strongest accessible source within each document; note missing primary locators as a limitation.
- **Output:** source-family map, bounded principle candidate, limitations, disposition (STRENGTHENS/NARROWS or NO DURABLE CHANGE), what would change the answer.

## Case B — Three reports, one study
- **Corpus:** Construct three report summaries A/B/C that all cite one original study S1; add an unrelated practitioner opinion P1.
- **Challenge:** Claim "three independent studies prove the mechanism."
- **Expected:** independent primary empirical families = 1; P1 does not create another independent study; reject high confidence gained by repetition; NEW LEAD/NO CHANGE pending sufficient support.

## Case C — Practice adoption vs reported effect
- **Corpus:** Two separate church primary manuals document an apprentice handoff, without outcome comparison; an organizational blog says "our disciples are multiplying."
- **Challenge:** Claim "this model causes four generations of disciple-makers."
- **Expected:** independently documented practice across two organizations; reported outcome requires unit, timeframe and verification. Practice Intelligence candidate; no causal high-confidence principle. Specific G0→G4 human-chain claim is NOT established.

## Case D — Contradiction, version and index consistency
- **Corpus:** Existing principle PR-001, new high-quality finding that narrows its population, and a second report repeating the older finding.
- **Challenge:** Update knowledge.
- **Expected:** retain PR-001 and previous version, NARROWS with evidence+confidence rationale; second report does not boost independence. Update topic owner and Master Index; if one write fails report OUT OF SYNC. No new PR-002.

## What counts as passing

- Trace actual accessed files and original underlying source families.
- Produce a candidate-disposition table, not an unqualified essay.
- Clearly distinguish **mechanism support** from proof of **individual spiritual reproduction**.
- Preserve uncertainty, older IDs and topic index ownership.
- Never claim a Drive artifact update without a verified write.
- Do not equate a passing static schema check with a passing behavioral case.
